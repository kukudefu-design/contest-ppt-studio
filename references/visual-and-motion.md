# 风格展板、逐字矢量与动效

## 图片预览契约

未指定风格：3 个方向，各 1 张展板。已指定风格/参考图：1 个方向，1 张展板。**每张都包含封面、典型内容页、结尾页**，不是三个封面，也不是三张无结尾的内容页。展板之外可附色板和一句适配理由，但不能代替三页视觉。

三方向的差异来自主题、受众、构图、字体、色彩与材质，不只换背景色。使用同组已知内容便于比较；未定稿内容标“示意/暂定”，避免用假成果烘托效果。不要默认所有项目都科技蓝、金色粒子或整齐卡片阵列。

使用可用生图能力生成真实图片并显示。生图 prompt 指定三种页面、主题、选定事实范围、字体与层级、背景层次和风格；参考图用于视觉关系而非提取未经确认的事实。生成文字有错误时修正或标明示意，关键正式文字后续原生重建。

若官方模板已锁定母版、封面、字体或配色等视觉系统，按“已有指定风格”提供 1 张合法填充展板，不要求三种差异。只规定内容栏目、外观仍自由的模板，按未定风格提供 3 个方向。边界不清时查实际规则和文件，只问影响当前选择的一个关键问题。

固定页在展板中使用原页渲染，仅在获准区域设计，不把固定页重绘来迎合风格。若图片生成不可用，先检查可用的真实渲染替代能否满足图片预览要求；仍不满足时给用户补齐或调整方案，不能仅发风格名称就进入全套制作。

## 封面与结尾页工艺

1. 确认标题文案、参赛信息与版式限制，后续转轮廓前避免未定稿标题反复重做。
2. 结合主题做逐字设计：字形、字距、比例、疏密及局部改造。主标题每个可见字为独立可选矢量轮廓或由该字多个路径组成的独立组；记录原始字串、字体与字序。
3. 优先导出为 PPT 原生自由形状/自定义几何。每字 SVG 图片与原生自由形状分别记录；只有图片、整词 SVG 或一组不可逐字选择的路径不能称“逐字原生矢量”。若采用每字 SVG，先验证目标软件实际调色/解组能力并明确编辑边界。
4. 副标题、参赛信息与正文使用文本框，通过字体、配色、间距和装饰呼应主标题；不要一并烧进背景图。
5. 搜集 5–10 张贴主题候选素材，记录来源、用途、真实/生成和取舍。选择适合构图的少量素材，不为凑数量全部堆入封面。
6. 用前景主体、中景标题与装饰、后景环境建立层次；按构图使用抠图、蒙版、遮罩、渐变、柔化或透明度，检查轮廓和边缘。
7. 标题光效按字色选择同色系/协调色光，保持统一光向、强度与对比；艺术字后方的柔化素材保持主体可辨。严肃学术风用克制柔光，科技创意风可强化。
8. 结尾页呼应同一字体与视觉语言，按比赛用途收束信息；不机械复制封面正文。

转轮廓后只能改形状、颜色和排布，不能直接改字。源文件保留文字内容和生成方式，方便更换标题后重建。字体不存在、缺字或许可不清时使用可用合规字体或提出替代，不用相似汉字、空框或图片掩盖缺字。

## 原生对象优先级

| 元素 | 默认实现 | 必须核对 |
|---|---|---|
| 正文/副标题/参赛信息 | PPT 文本框 | 字符可改、字体替换、换行、超出边界 |
| 数据图表 | 原生图表及可修改数据 | 类型与数据一致、嵌入数据有效、标签与单位准确 |
| 表格 | 原生表格或清晰组织的可编辑文本/线条 | 单元格文字与行列关系可改；具体实现写入报告 |
| 流程/路线图 | 原生形状、文本、连接线 | 关系语义、箭头端点、分组与编辑粒度 |
| 主标题 | 每字独立矢量轮廓，优先原生几何 | 字数/字序、独立选择、填色与形状可修改 |
| 装饰/蒙版/渐变/柔光 | 原生或矢量优先 | 后端实际支持，导出后无丢失 |
| 照片/抠图/复杂材质 | 可替换图片 | 来源、裁切、分辨率、透明边缘与真实性 |

用户接受为可编辑性做视觉简化。若核心要求仍无法实现，说明具体对象与方案供用户选择，不擅自用纯文本标题或整图替代逐字矢量。

## 内容页与动画

依据页面任务调整版式、密度和图表，不机械复制封面特效。所有正式文本与证据在导出后可读，避免标题碰撞、脚注过小、图像压字和流程箭头漂浮。

逐元素精细编排文字、图形和装饰的进入。每个参与元素有明确身份及动作；静止、免动或锁定对象也记录原因，不能用“全部对象统一淡入”掩盖未编排。必要时一项语义内容保留可编辑组，再针对组设计动作；不要为动画把图表烘焙成图片。

为每页写 `对象标识 → 讲述作用 → 进入效果 → 顺序 → 触发方式 → 时长/延迟`。区分单击、与上一项同时和上一项之后；控制总节奏，允许同一单击触发多个逐元素动作。装饰动画服务层次和节奏，官方禁改对象保持规定状态。

从实际导出的对象ID建立映射。目标缺失或重建后ID变化时同步修正动画。把原生图表、组、子形状的目标粒度写清，检查文字不会在对应图形或解释关系之前无意剧透。

整页切换与页内动画分别编排。GIF、视频、动画JSON或“已写计划”不能代替 PPTX 的实际对象动画。渲染静态帧不证明动画正确；目标软件中检查触发顺序、延迟、时长和完整讲述节奏。
